A premium, minimalist AI-powered language translation web app. Translate text instantly across 20 languages with a beautiful glassmorphism interface inspired by Apple design principles.

## Description

LinguaX is a production-ready, zero-dependency translation tool built with vanilla HTML, CSS, and JavaScript. It leverages the free MyMemory Translation API to deliver fast, accurate translations in a sleek dark-mode interface with electric violet accents.

## Features

- **20 Languages** — English, Tamil, Hindi, French, Spanish, German, Japanese, Chinese Simplified, Arabic, Portuguese, Korean, Italian, Russian, Dutch, Turkish, Bengali, Urdu, Malay, Indonesian, and Swedish
- **Instant Translation** — One-click translation powered by MyMemory API
- **Language Swap** — Quickly reverse source and target languages with an animated swap button
- **Smart Input** — Auto-resizing textarea with live character counter (500 char limit)
- **Copy to Clipboard** — One-click copy with success toast notification
- **Toast Notifications** — Elegant slide-in alerts for errors and confirmations
- **Premium UI** — Glassmorphism cards, gradient orbs, animated grain texture, and smooth transitions
- **Fully Responsive** — Optimized for desktop, tablet, and mobile
- **Keyboard Shortcut** — `Cmd/Ctrl + Enter` to translate

## How to Run

No build step or dependencies required.

1. Clone or download this repository
2. Open `index.html` in any modern web browser

```bash
# Option 1: Direct open
open index.html

# Option 2: Local server (recommended)
npx serve .
# Then visit http://localhost:3000
```
